# Cludoku — Object / Furniture Generation Prompts

**How to use:** Attach `assets/reference/style-reference.png` for the style. Save each as `object-<name>.png`, 512×512, transparent PNG. These are placed by the app into individual board cells (they're the clue anchors — "next to the plant," "two rooms from the table").

**Display rules (so they sit on the board consistently):**
- Viewed from a slight HIGH overhead 3/4 angle — recognizable from above but not flat (a pure top-down chair is unreadable). Same angle on every object.
- One soft drop shadow beneath each so it reads as sitting on the floor.
- Transparent cutout (generate on plain white, then knock out). Centered on a 1:1 square canvas with empty margin, consistent moderate scale so a lamp isn't dwarfed by a bed.
- No baked floor or background — the room floor shows through behind it.

Each prompt below is complete and copy-paste ready.

# Cludoku — Cast Generation Prompts

**How to use:** Attach `assets/reference/style-reference.png` to every generation so each suspect matches the locked Cozy Cartoon Noir anchor. Generate the full cast in one batch for consistency. Keep image-1's tight head-and-shoulders crop. Generate on plain white, then cut out for transparency. The prop + face are the real identifiers; the build also assigns each token a distinct colored ring per case so colors never blur at token size.

**Framing rules (in every prompt):** clean simple curved lower edge, torso cropped at mid-chest, consistent across the whole cast so every suspect crops identically into the round token; and one hand raised HIGH into frame near the chin/upper chest holding the suspect's prop — kept high so the gesture survives the circular token crop and fills the case-file card. The whole cast follows this one rule.

Each prompt below is complete and copy-paste ready.

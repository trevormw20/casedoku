# Cludoku — Room Floor Generation Prompts

**How to use:** Attach `assets/reference/style-reference.png` for the style (line weight, palette, shading, paper grain), but note the reference is a character bust — these rooms must be rendered as a STRAIGHT TOP-DOWN (90° overhead) view. Save each as `room-<name>.png`, 1024×1024.

**Why floors only (the 3-layer board):**
- Each room is just its floor + ambient styling. NO walls, NO doors, NO furniture — furniture is placed as separate per-cell object icons, and walls + doorways are drawn by the app as an overlay. This keeps rooms modular and reskinnable.
- Seamless/tileable so the floor fills a 3×3 block at any board position and butts cleanly against the engine's wall layer.
- Keep the SAME straight top-down angle and lighting on all nine, or the mansion won't read as one house. Each room gets a distinctive flooring material so they're easy to tell apart.

Each prompt below is complete and copy-paste ready.

# Cludoku — Name Shortlist (with collision check)

Working name: **Cludoku** (Clue + sudoku). Catchy and on-genre, but "Clue/Cluedo" is a Hasbro trademark — avoid for a commercial release.

Each name below is tagged from a web collision scan:
**CLEAR** = nothing meaningful found · **CAUTION** = minor/adjacent uses or crowded theme · **TAKEN** = a clear existing game/app/product on that name (avoid).

> Not legal advice. This is a web-search pass, not a formal clearance. Before committing, run a USPTO/EUIPO trademark search and an exact-name check on the App Store, Google Play, and Steam for your top pick.

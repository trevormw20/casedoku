# Cludoku — Name Shortlist

Working name: **Cludoku** (Clue + sudoku). Catchy and on-genre, but "Clue/Cluedo" is a Hasbro trademark — leans close enough to be worth avoiding if this goes commercial. Below are alternatives, split into "-oku / -doku" suffix names (genre convention, like MURDOKU / CRIMOKU) and names without the suffix.

> Legal note: these avoid the obvious conflicts (Clue, Murdoku, Crimoku, existing puzzle brands), but I'm not a lawyer. Before committing commercially, run a proper trademark/clearance search plus a domain and app-store name check — especially for short single-word names.

## "-oku / -doku" names
- **Whodoku** — whodunit + sudoku. Top pick: playful, instantly readable, clean to own.
- **Suspectoku** — suspect + oku.
- **Sleuthoku** — sleuth + oku.
- **Detectoku** — detective + oku.
- **Mystoku** — mystery + oku.
- **Riddoku** — riddle + doku.
- **Casedoku** — case file + doku.
- **Manordoku** — mansion-mystery flavor.
- **Alibioku** — alibi + oku.
- **Proofoku** — proof/evidence + oku.

## Names without the suffix
- **Nine Suspects** — descriptive, memorable, very ownable.
- **Sleuthgrid** — coined; says exactly what it is.
- **Gridlock Manor** — puzzle + mansion mystery in two words.
- **Alibi Grid** — clean and evocative.
- **Nine Rooms** — minimal, mysterious.
- **Casefile Nine** — case-file vibe + the 9×9 nod.
- **Suspect Square** — puzzle + mystery.
- **Parlour Murder** — cozy whodunit tone.
- **Deducto** — coined single word.
- **Suspecto** — coined single word.
- **The Manor Files** — series-friendly.
